# Корпус — реальные раскроенные стены

Одна папка = одна **настоящая работа**, которую цех действительно раскроил и собрал.

```
corpus/
  2026-09-azizova-kuxnya/
    job.json      # id, дата, кто принял, origin: "cut-job", что реально отпилили
    wall.fdl      # сама стена в FDL
```

**Правила (V-CORPUS, `59` §3.3):**

- `origin` только `cut-job`. Сгенерированные случаи сюда не попадают никогда — им место в тестах.
- Не больше **10 работ в квартал**. Корпус, который растёт быстрее, чем человек успевает читать,
  это не проверка, а просто ещё один набор тестов.
- Принимает **человек**, и его имя стоит в файле. Автоматического приёма нет.
- Цель — около **50 работ**. Пока их нет, закон `V-CORPUS` в реестре стоит как `deferred`,
  и это честно: пустой корпус ничего не доказывает.

Механизм готов (`model/corpus.ts`). Добавить первую работу — это положить сюда папку.
