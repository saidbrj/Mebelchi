# L1a — нет общего объёма в покое (SPEC 06_LAWS)

Две доски пересекаются, если их коробки перекрываются **по всем трём осям** с ненулевой
глубиной. Касание гранями — не пересечение (полка на дне касается дна: это нормально).

Нарушение → **отказ** `REF-OVERLAP` с обеими досками. Почему отказ, а не предупреждение:
пересечение нельзя исправить следующим шагом, два куска плиты не могут быть в одном месте (G12).

Пример: полка `on S1.bottom inside +0` — касается дна, законно. Вторая такая же полка в то же место
→ `REF-OVERLAP [P5, P6]`, вторая не создаётся.
