# ids — устойчивые uid (SPEC G10)

У каждого узла есть uid: буква вида и номер. `M1` модуль, `S3` пространство, `D2` деление, `P7` деталь.
Счётчики лежат **в состоянии графа**, поэтому undo возвращает и их (G18), а один журнал
команд всегда даёт одни и те же uid (G17).

uid не меняется, пока узел существует. Путь для человека (`S0.2.1`) — другое, он появится с UI.
