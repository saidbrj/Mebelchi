# units — единицы (SPEC U01–U06)

Внутри ядра длина — **целые десятые доли миллиметра** (mm10): 16 мм = 160, 1.5 мм = 15.
Это единственная папка, где в коде есть число 10 (масштаб).

- `fromMm(mm)` → mm10, или `null`, если ввод точнее 0.1 мм. Вызывающий превращает `null` в отказ `REF-PRECISION` (U06): ядро не округляет молча.
- `toMm(v)` → мм для показа и для моста в Полигон (U05).
- `divide(total, weights, policy)` → целые части, **сумма точно равна целому** (U03).
  Остаток уходит по ключу профиля `residualPolicy`: `leftmost-absorbs` → первой части, `last-absorbs` → последней.

Пример: 1000 мм на 3 равные части = 10000 mm10 → `3334 + 3333 + 3333` (сценарий RT H3).
