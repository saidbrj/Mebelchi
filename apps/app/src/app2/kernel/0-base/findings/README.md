# findings — находки (SPEC 07_FINDINGS)

Находка = `{ код, серьёзность, узлы, текст, варианты }`. Варианты — это **команды, которые
пользователь может выбрать**; ядро их само не выполняет (P01).

- `refusal` — команда отказана, граф не изменён (G11).
- `blocking` — граф изменён, выпуск закрыт.
- `advice` — только сведения.

Каталог всех кодов с русскими текстами — [findings.findings.ts](findings.findings.ts). Каждая
папка функции перечисляет в своём `*.findings.ts`, какие коды она может выдать.

Здесь же тип `SettingDecl`: форма объявления ключа настройки для `*.settings.ts` (A04).
