# REPLACE (SPEC W11, G16, R14)

Пока одна форма: **убрать деталь** (`заменить на ничего`).

- У детали есть зависимые (на неё опираются, на ней крепят) → отказ `REF-HAS-DEPENDENTS`
  **со списком**. Каскадного удаления нет: мастер сам решает, что делать с зависимыми (R14).
- **Пространства зависимыми не считаются** (G16): грань пространства, которая опиралась на
  убранную доску, переходит к следующей поверхности — так из шкафа получается стол, когда убирают
  дно. Все сдвинувшиеся числа попадают в отчёт.
- Деталь паттерна убирают операцией паттерна (`убрать`), чтобы промежутки слились по правилу R04;
  здесь она даст отказ с подсказкой.
