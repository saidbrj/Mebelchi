# PATTERN (SPEC E08, W04, R04)

Повторение одного типа вдоль одной оси. Распределение описывает **промежутки**: `1:1:1` — это три
промежутка и две полки, потому что полка стоит **между** промежутками (Q70).
Промежутки — настоящие пространства со своими uid, в них можно ставить вещи, не распуская паттерн (Q67).

## Шесть операций, а не «перезадать список»

Идентичность промежутка следует за операцией (R04), поэтому команда всегда называет место:

| Операция | Что делает | Что с uid |
|---|---|---|
| `создать` | новый паттерн в пространстве | промежутки и участники рождаются |
| `доли` | меняет распределение, количество то же | **ни один uid не меняется** |
| `вставить` | делит промежуток надвое, добавляет участника | нижний промежуток сохраняет uid, верхний — новый |
| `убрать` | убирает участника, два промежутка сливаются | слитый сохраняет uid нижнего; содержимое верхнего переезжает **не сдвигаясь** |
| `отвязать` | одна деталь выходит из паттерна; паттерн делится на два, каждый в своей области | у отвязанной прежний uid, у двух новых паттернов новые uid |
| `сдвинуть` | отвязать и сдвинуть: **меняются только два соседних промежутка**, остальные закрепляются нынешним размером (Q54) | как у отвязки |
| `отпустить` | конец параметрического управления: все детали самостоятельные, промежутки становятся обычными пространствами между ними | **все uid прежние** (Z05) |
| `распустить` | убирает паттерн целиком | промежутки и участники уходят, пространство снова целое |

Менять количество через «доли» нельзя: команда откажет и скажет, что нужна вставка или удаление.

## Что происходит при слиянии

Грань исчезнувшего промежутка перестаёт существовать, поэтому ссылки на неё переносятся на слитый
промежуток **с сохранением места**: отступ пересчитывается на разницу граней, а пролёт, который
опирался на исчезнувшую грань, закрепляется своим текущим числом. Обе правки видны в отчёте.

## Отказы
`REF-ORPHAN` (деление занятого пространства, Q19) · `REF-NO-ROOM` · `REF-AMBIGUOUS` (в паттерне нет
участников, или количество меняют «долями») · `REF-MISSING-REF`.

## После отпускания

Ссылки живут, распределение — нет (R31): каждая деталь получает свою опорную грань и отступ,
а каждый промежуток становится пространством между соседними деталями. Поэтому ширина юнита
по-прежнему тянет полку, а высота её больше не двигает.
