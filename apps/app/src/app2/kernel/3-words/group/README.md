# GROUP (SPEC E10, W08, R13, Z10)

Группа — это **список узлов, которыми мастер управляет вместе**, как в Photoshop. Она **ничем не
владеет** и не несёт конструктивного смысла: распустить группу — значит забыть список, и больше
ничего (Z10).

| Операция | Что делает |
|---|---|
| `создать` | из выбранных узлов делает группу с именем |
| `добавить` · `убрать` | правит список |
| `распустить` | забывает список; узлы остаются как были |

Группа — обычная цель для SCOPE: «применить к этой группе». Этим она отличается от модуля, у
которого есть общие детали и конструктивный смысл.

**Отказы:** `REF-MISSING-REF` (узла нет), `REF-AMBIGUOUS` (пустая группа или узел уже в ней).
