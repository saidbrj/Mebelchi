# DRAG (SPEC W05) — сдвинуть и изменить размер

Три формы в этом срезе:

| Форма | Что меняет | Отказ |
|---|---|---|
| `module <ось> <размер>` | габарит модуля; всё, что на него ссылается, пересчитывается | меньше `minCarcassMm` → `REF-TOO-SMALL` |
| `part <доска> <сдвиг>` | доска `on` — её отступ; **доска деления** — её ячейка становится постоянной (размер + сдвиг), остальные доли делят остаток (DECISIONS §2.4, RT H1) | доска корпуса или `against` → `REF-LOCKED` |
| `size <доска> <ось> <длина>` | длина пролёта, объявленного числом | пролёт «от грани до грани» → `REF-LOCKED` (его размер задают грани) |

`REF-LOCKED` всегда называет, **что** надо двигать вместо этого: габарит модуля, доску, к
которой прижата деталь, или грань пространства.

Пересекла другую доску → `REF-OVERLAP`, ячейка не поместилась → `REF-NO-ROOM`: команда не
выполняется целиком (G11).
