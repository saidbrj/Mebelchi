# word — общий тип слова

`Word<C> = (graph, command, ctx) → Outcome<Draft>`. Контекст: профиль цеха и текущая
геометрия (DRAG доски деления берёт её текущий размер ячейки).

Здесь же `fullSpan(node, axis)` — пролёт «от грани до грани» узла: так PLACE говорит
«на всю ширину пространства» ссылкой, а не числом.
