# SCOPE (SPEC W10, E11, R50–R53)

«Применить к…» — у каждого изменения свой адрес. Цель разрешается **один раз** в список uid, и
в журнал попадают именно uid, а не условие: новая деталь старого изменения не получит (R52).

| Цель | Кому |
|---|---|
| `эта деталь` | одной |
| `все детали типа` | всем полкам юнита разом |
| `эта группа` | тем, кого мастер выбрал руками |
| `весь юнит` | всем деталям |
| `этот стык` | способу соединения и сквозной детали |

| Ключ | Значение |
|---|---|
| `слот` | материал через слот проекта: `ФАСАД-A`, `КОРПУС-B` (E12) |
| `способ` | способ соединения на стыке; выбор заводского снимает исключение |
| `насквозь` | кто из двух деталей сквозной (R37) |

У группы и цели **нет силы**: они только выбирают, к кому применить. Кто победит, решает порядок
команд, и это видно в отчёте (Q96).
