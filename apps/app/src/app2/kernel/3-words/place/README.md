# PLACE (SPEC W06) — любая доска где угодно

Главная функция App 2: **одна доска**, куда мастер решит. Слов вроде `ADD_RAIL_80` нет
(DECISIONS §10.2). Связь обязательна, направления по умолчанию нет (DECISIONS §9.4):

| Связь | Смысл | Куда растёт толщина |
|---|---|---|
| `on <грань пространства> inside` + отступ | лежит на открытой плоскости, внутрь | внутрь пространства |
| `on <грань пространства> outside` + отступ | то же, наружу | наружу |
| `against <грань доски>` | прижата к грани другой доски | **от** той доски (в доску расти нельзя) |

`on` без `inside|outside` → `REF-AMBIGUOUS` (сценарий RT J4). У `against` отступа нет: прижата — значит касается.

**Пролёты** по двум другим осям объявляются: «от грани до грани» (`fullSpan`, ссылка) или
«от грани + отступ, длина» (число пользователя). Пролёта нет → `REF-AMBIGUOUS`.

**Толщина:** из профиля, или объявленная (проставка 25) — объявленная главнее.

Пример: полка на 300 выше дна пространства S1 (568 × 688 × 560):
`on S1.bottom inside +300`, пролёты x и z на всю ширину → доска 568 × 16 × 560 на высоте 316–332 от низа модуля.

**Деталь может выйти за пространство** (DECISIONS §9.3). Но занять объём другой доски не может:
`REF-OVERLAP` (L1a), и команда не выполняется целиком.
