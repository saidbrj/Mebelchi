# to-poligon — мост (SPEC O02, O08, P04, U05)

```
ядро                       мост                     Полигон
детали и отрезки  ──▶ мм и роли Полигона ──▶ кромка · раскрой · сверление · SWJ008
```

**Полигон размеры не пересчитывает** (P04). Мост отдаёт то, что посчитало ядро, и переводит
mm10 → мм **одной функцией** (U05). Толщина — по нормали детали, длина — больший из двух
оставшихся размеров, ширина — меньший: так деталь ложится на лист.

## Сверка «одна правда»

`disagreements()` берёт те величины, которые Полигон **умеет считать сам** (проём, глубина полки,
ширина задника, ширина фасада), и сравнивает их с числами ядра. Расхождение — это не спор, а
**красный тест**: значит, два слоя разошлись в смысле, и чинить надо смысл, а не число.

Сегодня сверка проходит: проём 568, полка 538 (560 − 20 − 2) — у ядра и у Полигона одинаково,
хотя считают они по-разному: ядро — по отступам типа детали (R24), Полигон — своей формулой.
