# from-corpus — кухни корпуса через ядро (SPEC T07)

Самая жёсткая проверка: **тот же шкаф, собранный ядром, должен дать те же детали**, что Полигон
выпускает сегодня. Формулы у слоёв разные, значит совпадение чисел — это совпадение смысла.

```
корпус Полигона              ядро                       сверка
CabinetFill 900×720×600  ──▶ CUBE + PATTERN        ──▶  деталь за деталью
{ shelves: 2 }               две полки 884 × 578        длина · ширина · толщина
```

**Ядро меряет снаружи, Полигон — по осям стоек.** Стойка общая с соседом, поэтому шкафу
принадлежит её половина: наружная ширина = ширина Полигона + толщина доски (`outerWidthMm`).

## Что уже сверяется и чего ядро ещё не умеет

| Роль | Состояние |
|---|---|
| полка | ✅ сверяется на настоящих шкафах корпуса |
| боковины, дно, крышка | ✅ считает ядро; в корпусе они приходят из стены, а не из наполнения |
| фасад · ящик · задник | ещё не выражаются словами ядра — перечислены честно, а не спрятаны |

`unsupported()` называет те наполнения, которых ядро пока не умеет: пока список не пуст, кухня
целиком через ядро не проходит, и это видно, а не забыто.
