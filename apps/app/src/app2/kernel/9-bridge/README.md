# 9-bridge — мост в Полигон

Единственный слой, который импортирует `src/poligon`. Здесь ядро **отдаёт готовые детали**, а
Полигон делает то, что умеет: кромка, раскрой, сверление, SWJ008.

| Папка | Что | SPEC |
|---|---|---|
| [to-poligon/](to-poligon/README.md) | детали ядра → `FillPart` Полигона; сверка чисел «одна правда» | O02, O08, P04, U05 |

| [from-corpus/](from-corpus/README.md) | шкафы корпуса, собранные ядром, против деталей Полигона; честный счёт, чего ядру не хватает до полной кухни | T07 |
