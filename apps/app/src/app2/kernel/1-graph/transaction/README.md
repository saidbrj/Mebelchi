# transaction — всё или ничего (SPEC G11, G14, G15, G18, G19)

`commit(prev, draft, checks)`:
1. слово (слой 3) уже построило **черновик** графа или отказало;
2. черновик вычисляется целиком (`evaluate`);
3. проверки законов (их передаёт верхний слой, граф их не импортирует);
4. **любой** отказ → возвращается **тот же объект** `prev`, граф не тронут;
5. иначе новое состояние + отчёт изменений: что добавлено, удалено, какие коробки сдвинулись.

**Ничего автоматически (G14):** слово объявляет, сколько деталей оно добавляет или убирает.
Если после команды разница другая — это ошибка в коде ядра, и `commit` бросает исключение.

**История (G18):** у состояния есть ссылка на предыдущее. `undo` возвращает именно тот объект,
поэтому граф побитово тот же, со счётчиками uid.

**Правка профиля (M03, G19):** `reprofile` не может отказать: профиль не принадлежит модулю.
Всё, что сломалось, становится блокирующим `WARN-EXTERNAL-CONFLICT` с вариантами. Сначала
вызывается `impactOf`, чтобы пользователь увидел, что изменится, **до** принятия правки.
