# model — узлы графа (SPEC 04_GRAPH)

Оси: x слева направо, y снизу вверх, z спереди назад. Перед модуля — плоскость z = 0.

| Узел | Объявлено |
|---|---|
| `module` | габарит w×h×d (mm10), имя профиля |
| `space` | либо 6 граней-ссылок (`bounds`), либо «ячейка №i деления D» (`cellOf`) |
| `division` | пространство-хозяин, ось, правила ячеек (`ratio` / `fixed` / `flex`), доска-граница или нет, uid ячеек и досок |
| `part` | роль, хозяин, толщина (из профиля или объявленная), положение по нормали и пролёты по двум другим осям |

**Положение детали по нормали** — один из двух видов:
- `plane`: грань какого-то узла + направление роста толщины (+1 / −1) + отступ;
- `boundary`: «граница №i деления D» — положение считает деление.

**Пролёт** по оси: `between` (от грани до грани) или `sized` (от грани + отступ, длина).

Ни одно число в модели не вычислено: только ссылки и объявленные значения.

`dependentsOf(graph, id)` — узлы, чьи объявления ссылаются на `id` (G16). Нужен отказу
«сирота» (Q19) и будущему удалению.
