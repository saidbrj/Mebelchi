# context — что App 1 передаёт в App 2 (SPEC R60–R65)

Единственная дверь между приложениями. **Слова «модуль» здесь нет**: App 2 видит только свой юнит
и чужие детали, помеченные «только для чтения».

```
UnitContext
├── unit       какой юнит: габарит и тип (нижний · верхний · пенал)
├── profile    имя профиля цеха
├── external   чужие детали-границы: чьи они, с какой стороны, толщина, тип — только чтение
├── support    на чём стоит или висит: пол · цоколь · стена · каркас
├── neighbours что рядом с каждой стороны: юнит · стена · свободно
└── walls      стены поблизости и расстояние до них (для движения, L1b)
```

**Правила, которые держат границу:**
- id чужой детали всегда с двоеточием (`M4:P7`) — ядро таких id не выдаёт никогда, поэтому
  случайно «своей» чужая деталь стать не может;
- у App 2 нет команды, которая пишет в `external`: изменить общую боковину можно только из App 1
  (R22, R63);
- «сделать боковину общей» из App 2 — это **просьба** к App 1, а не действие.

Пока App 1 не написан, вместо него — [фикстуры](context.fixtures.ts): юнит отдельный, юнит с
общей правой боковиной и юнит между двумя соседями. Числа живут там, а не в коде ядра.
