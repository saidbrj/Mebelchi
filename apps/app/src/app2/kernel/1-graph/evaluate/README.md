# evaluate — объявления → геометрия (SPEC O02, G13)

`evaluate(graph, env)` превращает объявления в коробки (min/max по x, y, z в mm10) для каждого
пространства и детали. Вызывается после **каждой** команды заново: запомненных размеров нет.

- **Модуль:** от 0 до габарита.
- **Пространство:** 6 граней = координаты граней, на которые оно ссылается; ячейка деления берёт
  отрезок от своего деления.
- **Деление:** длина хозяина по оси − доски-границы − fixed-ячейки = остаток; остаток делится между
  `ratio` и `flex` по весам (`flex` = вес 1) функцией `divide` (остаток — по `residualPolicy`).
- **Деталь:** по нормали — от грани в сторону `dir` на толщину; по двум другим осям — пролёты.

Профиль приходит параметром `env` (слой 2 реализует его), поэтому граф не импортирует настройки.

**Происхождение (G13):** для каждой детали и ячейки записано, откуда число:
`толщина 16 ← profile:qorasu carcassThicknessMm`, `ячейка 1882 ← доля 1 из 3 (остаток 5648)`.

**Проблемы** (размер ≤ 0, не помещается, цикл, висящая ссылка) возвращаются списком находок.
Транзакция превращает их в отказ, а правка профиля — в блокирующее предупреждение (G19).
