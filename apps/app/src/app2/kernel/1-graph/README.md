# 1-graph — граф конструкции

Граф хранит **только объявленное** (SPEC O01). Геометрию каждый раз выводит `evaluate` (O02),
поэтому запомненного размера, который мог бы разойтись с формулой, нет.

| Папка | Что | SPEC |
|---|---|---|
| [model/](model/README.md) | узлы (модуль, пространство, деление, деталь), ссылки на грани, зависимые | G01–G05, G09, G16 |
| [evaluate/](evaluate/README.md) | объявления → коробки в mm10 + происхождение каждого числа | O02, G13 |
| [transaction/](transaction/README.md) | «всё или ничего», отчёт изменений, история и undo | G11, G14, G15, G17, G18 |
| [context/](context/README.md) | что App 1 передаёт в App 2: юнит, чужие границы только для чтения, опора, соседи, стены; фикстуры вместо App 1 | R60–R65 |
