# Ядро App 2 (kernel)

Здесь находится всё про движок App 2: что он обязан делать (`SPEC/`), как его пытались сломать
(`redteam/`), стражи архитектуры (`guards/`) и сам код по слоям.

```
      ЯЗЫК MEBELCHI (15 слов)        ← жесты UI и текст ИИ превращаются в команды
               ↓
      ГРАФ КОНСТРУКЦИИ               ← что пользователь объявил (1-graph)
               ↓
      УНИВЕРСАЛЬНОЕ ЯДРО             ← настройки, геометрия, законы, компоненты, фурнитура, движение
               ↓
      ПОЛИГОН (../poligon)           ← раскрой, кромка, сверление, SWJ008 (не переписывается)
               ↓
      CUT / DRILL / EDGE / DXF
```

## С чего начать чтение

0. [MAP.md](MAP.md): **одна страница** — кто над кем, кто чем владеет, дорожная карта со статусом.
1. [SPEC/README.md](SPEC/README.md): оглавление спецификации. **SPEC главнее промпта Судьи.**
2. [SPEC/00_PRINCIPLES.md](SPEC/00_PRINCIPLES.md): 12 принципов. Их не нарушает ни одна функция.
3. [SPEC/05_WORDS.md](SPEC/05_WORDS.md): контракт каждого из 15 слов.
4. [redteam/README.md](redteam/README.md): 52 злых сценария и что они уже нашли в SPEC.

**Посмотреть в 3D:** `npm run dev` в `apps/app`, затем `/kernel.html` — срез фазы 2
(`src/kernel-demo/`, страница ничего не считает сама, только зовёт `index.ts`).

## Что умеет ядро сегодня — и где это в срезе

| Команда | Операции | Где в `kernel.html` |
|---|---|---|
| CUBE | создать юнит; факт из App 1 «боковины общие» | «Юнит — CUBE», переключатель «стойки общие» |
| DRAG | габарит юнита · сдвиг детали · длина пролёта | «Юнит», панель выбранной детали |
| PATTERN | создать · доли · вставить · убрать · отвязать · сдвинуть · отпустить · распустить | «PATTERN в …», панель детали |
| PATTERN на грани | фасады: створки по ширине юнита, поле и зазор из профиля | «Фасады — PATTERN на грани юнита» |
| PLACE | доска на грань пространства или к грани доски | «PLACE — доска в …» |
| REPLACE | убрать деталь | панель детали, «Удалить» |
| GROUP | создать · добавить · убрать · распустить | «Группы — GROUP» |
| SCOPE | слот материала: деталь · тип · группа · юнит; способ стыка; кто насквозь | «Слоты материалов», режим «Стыки» |
| профиль | значение с диапазоном, отчёт о влиянии | «Профиль цеха — M03» |
| отмена | шаг назад | «UNDO» |
| мост | детали в терминах Полигона + сверка «одна правда» | «В раскрой — мост в Полигон» |

Стыки выводятся сами, их не надо создавать: режим «Стыки» проходит по ним подряд.

## Одна функция = одна папка из 5 файлов

```
3-words/split/
  README.md            что делает, примеры с числами, отказы, ссылки на SPEC (по-русски)
  split.ts             одна экспортируемая функция, чистая, без чисел
  split.settings.ts    КАКИЕ ключи профиля / паспорта читает и их диапазоны (значений нет)
  split.findings.ts    коды отказов и предупреждений, тексты, варианты для пользователя
  split.test.ts        тесты с тегами [spec:W04] [law:L1a] [ruling:Q19]
```

Файл длиннее ~250 строк делится на соседние (`split.ratio.ts` со своим тестом).
