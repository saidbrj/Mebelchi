# 12 — Тесты

### T01 — Уровни
| Уровень | Что проверяет | Пример |
|---|---|---|
| L0 математика | mm10, деление, остаток | 1000 / 3 → 3334 + 3333 + 3333 |
| L1 геометрия | граф: грани, вложенность, пересечение | CUBE 600×720×560 → 4 доски нужных размеров |
| L2 конструкция | законы L1–L5 | полка висит → WARN-SUPPORT |
| L3 профиль | тот же журнал, другой профиль | 16 → 18: внешние размеры те же, внутренние меньше |
| L4 заказы | Gold / Silver | ~200 заказов MIND |
| L5 отказы | отказ, а не ремонт | X11, X12, N30, R075, C03 |
| L6 изменение после постройки | удалить, снять деление, заменить, отвязать, сменить хозяина | красная команда A–J |

### T02 — Теги
Каждый тест несёт в названии хотя бы один тег: `[spec:W04]`, `[law:L1a]`, `[ruling:Q19]`, `[rt:E1]`.
Страж проверяет, что каждый тег ведёт на существующий id и каждое W, L и Q покрыто тестом (с фазы 4).

### T03 — Gold / Silver / Bronze
- **Gold** — ядро посчитало, человек подписал (T04). Проверяет **точные числа**. Удаляет только тот, кто подписал.
- **Silver** — ядро посчитало, выполнены инварианты (сумма ячеек = проём, нет пересечений, сумма
  деления точна), подписи нет. Проверяет **инварианты**, не числа.
- **Bronze** — есть только вердикт Судьи. Это `it.todo` с текстом ожидания; числа **не проверяются**
  (Судья ошибся в 6 из ~57 ответов поколения 4, все мягче, чем надо).

### T04 — Кто подписывает (Q33)
- Числа производства (раскрой, сверление, зазоры, ЧПУ): `verifiedBy: "Улугбек (Цех Корасу)"`, дата.
  Без этой подписи тест не Gold и не может блокировать выпуск из-за расхождения в десятых долях.
- Архитектура ядра (законы, формулы отступов, инварианты графа): `approvedBy: "Шохибузрук"`, номер решения.

### T05 — Золото никогда не берётся из Судьи
Порядок: заказ + программа + версия правил → **ядро считает** → человек проверяет → заморозка.
Вердикт Судьи — только подсказка, что ожидать (ENGINE_PLAN §2.1).
