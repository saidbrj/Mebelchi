# 07 — Находки и статус

## Форма находки

Каждая находка — это `{ код, серьёзность, узлы, текст (ru), варианты[], закон/решение, происхождение }`.
Варианты — это **команды, которые пользователь может выбрать**, а не действия, которые ядро
делает само. Пример: `WARN-DOORHIT` → [поставить проставку не уже входа створки из паспорта] [петля H155] [убрать ящик].

Серьёзность: `refusal` (граф не изменён) · `blocking` (выпуск закрыт) · `advice` (только сведения).

## Отказы (граф не изменён, G11)

| Код | Когда | Источник |
|---|---|---|
| **REF-MISSING-REF** | ссылка на узел, которого нет | G10 |
| **REF-AMBIGUOUS** | пришлось бы угадывать (нет inside/outside, неясный пролёт) | P03 |
| **REF-PRECISION** | ввод точнее 0.1 мм | U06 |
| **REF-OUT-OF-SCOPE-APP1** | вся кухня, цоколь, ножки, подвес, столешница | P08 |
| **REF-OUT-OF-SCOPE-APP3** | непрямые углы, фаски, вырезы, пазы как форма, рамочный фасад | P08 |
| **REF-OVERLAP** | статичное пересечение объёмов | L1a |
| **REF-ORPHAN** | предмет остаётся без ячейки | Q19, Q26 |
| **REF-NO-ROOM** | fixed-размеры не помещаются в хозяина | W04, W05 |
| **REF-TOO-SMALL** | меньше минимального полезного или минимального корпуса | L5, Q8 |
| **REF-CUTS-PROJECTION** | внутреннее деление режет доску, спроецированную фасадом | Q27 |
| **REF-LOCKED** | меняется размер с маркой 🔒 | W13 |
| **REF-CYCLE** | цикл ссылок или определение внутри самого себя | G16, C08 |
| **REF-HAS-DEPENDENTS** | удаление узла, на который ссылаются | G16 |
| **REF-HW-REQUIRES** | требование паспорта не выполнено; перечислены подходящие паспорта | H04 |
| **REF-OUT-OF-RANGE** | значение настройки вне объявленного диапазона | S05 |

## Блокирующие предупреждения (граф изменён, выпуск закрыт)

| Код | Когда | Источник |
|---|---|---|
| **WARN-MOTION-HIT** | удар в движении | L1b |
| **WARN-ASSEMBLY** | деталь нельзя поставить ни в каком порядке | L1c |
| **WARN-DOORHIT** | ящик за дверью, вход створки не компенсирован | L1d |
| **WARN-CAPACITY** | больше заявленной ёмкости | L2 |
| **WARN-STOCK** | лист, станок, транспорт | L3 |
| **WARN-SUPPORT** | нет пути опоры, деталь висит | L4 |
| **WARN-NO-SUBSTRATE** | фурнитуре не на что крепиться (ХДФ, пусто) | H03 |
| **WARN-REFLOW-HEIGHT** | после перераспределения ящик не влезает по высоте | Q32 |
| **WARN-EXTERNAL-CONFLICT** | правка профиля или определения создала проблему в модуле | G19 |
| **WARN-ORPHAN-OVERRIDE** | переопределение указывает на узел, которого в новой версии нет | C07 |

## Советы (ничего не закрыто)

| Код | Когда |
|---|---|
| **ADV-LONG-SPAN** | длинный пролёт без связи (раньше Полигон добавлял связующую полку сам; теперь только советует) |
| **ADV-RASTER-SNAP** | положение привязано к растру 32 и сдвинулось на столько-то (O06) |
| **ADV-ASSUMED** | результат зависит от значения с пометкой `assumed` |

## Статус по 4 осям

| id | Ось | OK | FAIL | INCOMPLETE |
|---|---|---|---|---|
| **ST-GEOMETRY** | геометрия | всё построено | — (отказы не доходят до статуса) | — |
| **ST-RULE** | законы | нет блокирующих | есть блокирующие | — |
| **ST-DATA** | данные | все паспорта и значения подтверждены | паспорт запрещает | поле отсутствует или значение `assumed` / `test` |
| **ST-MANUFACTURING** | производство | Полигон выпустил раскрой | лист / станок / транспорт | ещё не запускалось |

Соответствие вердиктам MIND: `PASS` = всё OK · `PASS*` = DATA INCOMPLETE · `PASS⚠` = RULE FAIL
только из-за блокирующих предупреждений, которые пользователь видит · `PASS_REFUSAL` = отказ на
невозможное. Вердикты MIND — язык Судьи, ядро говорит статусами.
