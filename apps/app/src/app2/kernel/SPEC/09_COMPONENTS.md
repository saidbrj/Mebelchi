# 09 — Компоненты: определение, экземпляр, переопределение

### C01 — Определение (Definition)
Сохранённый элемент каталога: объявления узлов (не геометрия), марки ↔ 🔒 ⋯ ⚓, минимальный
полезный размер (L5), уровень. Каждая правка создаёт **новую версию**, старые остаются.

### C02 — Четыре уровня каталога, один формат
компонент (ящик, полка-обувница) · тип (шкаф-пенал) · модуль (готовая ячейка кухни) ·
набор / стиль. Все четыре галереи хранят **один и тот же формат** определения; уровень — это метка.

### C03 — Экземпляр (Instance)
Ссылка на определение и версию + хозяин + якорь + список переопределений. Состояние:
**BOUND** (следует за определением) или **DETACHED** (после `release`, W09).

### C04 — Правка определения в том же проекте
BOUND-экземпляры **этого проекта** следуют сразу, после отчёта о влиянии (G19). Переопределения
экземпляра сохраняются: самый узкий уровень побеждает (S02).

### C05 — Другие проекты закреплены на версии
Экземпляр помнит версию (`pinnedVersion`). В другом проекте правка определения показывается как
«доступно обновление» и применяется только операцией M05. Выпущенный в производство проект не
меняется никогда: выпуск хранит снимок.

### C06 — Переопределение (Override)
`{ путь узла внутри определения, ключ, значение }`. Явное, в списке, считается. Правка одного
экземпляра меняет **только** его.

### C07 — Переопределение без цели
Если новая версия определения удалила узел, на который указывает переопределение, экземпляр
получает блокирующее `WARN-ORPHAN-OVERRIDE` с вариантами: снять переопределение · отвязать
экземпляр (DETACHED на старой версии) · вернуть прежнюю версию. Молча переопределение не пропадает.

### C08 — Вложенность без циклов
Определение может содержать экземпляры других определений. Определение, которое (прямо или
через вложенность) содержит само себя, → `REF-CYCLE`.

### C09 — Масштабирование по маркам
При изменении хозяина: ↔ растягивается, 🔒 держит размер, ⋯ меняет количество, ⚓ держит отступ
от своей грани. Если 🔒-части не помещаются → `REF-NO-ROOM`; если меньше минимального полезного →
`REF-TOO-SMALL`. Размер 🔒 внутри экземпляра меняется только переопределением, иначе `REF-LOCKED`.

### C10 — Отвязка (release)
DETACHED-экземпляр получает копию **текущих объявлений** (с переопределениями, уже применёнными),
новые uid, и больше не связан с каталогом. Правки определения его не трогают.

### C11 — Что относится к App 3
Форма одной детали (окно в двери, фреза, фаска, рамка Шейкер) делается в App 3 как компонент.
App 2 ставит его целиком и меняет REPLACE. Глубина такого компонента берётся из **его определения**,
а не вычисляется ядром (ответ основателя 13).
