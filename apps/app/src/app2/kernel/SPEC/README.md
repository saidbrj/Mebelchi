## Как объявляется id

id объявляется **только** двумя способами (так его находит страж `guards/spec.test.ts`):

- заголовком: `### W04 — SPLIT`
- первой ячейкой таблицы жирным: `| **G03** | … |`

Id не переиспользуется. Отменённое правило остаётся с пометкой **ОТМЕНЕНО** и ссылкой на замену.

## Как меняется SPEC

1. Сначала находка (тест, красная команда, заказ), потом правка.
2. Crutch guard (Q-правило 9.1): сначала проверяем, выражается ли случай существующими словами
   и правилами. Новое слово появляется только когда старыми выразить невозможно.
3. Правило, которое называет тип мебели, конкретный аксессуар, миллиметры или одно исключение,
   **подозрительно** (DECISIONS §10.7) и требует решения основателя.
4. Каждая правка SPEC повышает версию в этом файле.
