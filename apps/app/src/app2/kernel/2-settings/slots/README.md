# slots — слоты материалов (SPEC E12, S03)

Слот — **именованное общее значение проекта**: `КОРПУС-A`, `ФАСАД-A`. Деталь ссылается на слот,
а не на материал, поэтому смена слота перекрашивает всё, что на него ссылается, одним действием.

```
ФАСАД-A = белый глянец     ← поменяли здесь
   ↑        ↑        ↑
дверь 1  дверь 2  дверь 3  ← поменялись все
```

Какой слот у детали по умолчанию — таблица `things/tables/slots`, поле `byType`: у корпусных
деталей `КОРПУС-A`, у фасадов `ФАСАД-A`. В коде ядра ни одного имени слота нет.
