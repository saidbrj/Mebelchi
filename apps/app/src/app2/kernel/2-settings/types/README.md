# types — правила профиля по типу детали (SPEC E07, R24)

Ядро не знает слов «полка» и «ящик». Оно спрашивает: **какие отступы у этого типа детали с этой
грани** — и получает ответ из файла настроек `things/tables/part-types`, а числа из профиля цеха.

```
тип «полка»:  front = shelfSetbackMm (20)      →  полка = глубина − 20 − 2 = 538
              back  = backOverlayShelfGapMm (2)
```

Отступ применяется только к пролёту **«по месту»** (от грани до грани, R24): объявленное числом
не трогается никогда. Меняете профиль — меняются все полки; меняете тип детали — меняются правила
только этого типа. Ни одного названия типа в коде ядра нет.
