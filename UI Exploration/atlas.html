Закон: частота определяет расстояние

Контрол ближе, чем заслуживает частота — шум (ошибка «+», ошибка цвета). Дальше — трение (ошибка Bazis). Кликни кольцо — отфильтруешь все функции по нему.

§2

Девять групп функций

Полный инвентарь операций. Цвет точки = кольцо. Бейдж = класс частоты (M/H/P/W/A/O).
§5

Грамматика жестов

Один жест = один смысл, везде. Ни один жест не делает двух вещей.
