01 Что общего у всех трёх

Все три версии стоят на одной модели и одних фактах из базы — расходятся только в том, как навигировать. Линия и секция как первоклассные сущности; объём действия Локально·Линия·Ряд·Все; амбиентный счётчик листов + цена; decor как поздняя привязка; и выход в детальный PDF («Паспорт изделия» + «Лист фасадов»), потому что именно это, по вашим словам об imos, «даёт доверие».

02 Лучшее, что вошло из исследований

R7U_0 verdict · L1
Тип-первым, drag — грубо
Мастер знает размер: тап → numpad с выражениями (720−2×18). Детент 50 мм, не 32. → V1·04, V2·02
R7U_0 · L2 / imos P4
Мульти-выбор = тумблер
Не долгое нажатие (рушится на грубых руках). Бейдж «N секций», гашение остального. → V1·09, V2·03
R7U_0 · §3 камера
Тап = выбор + тихий pivot
Камера не летит на каждом выборе. Двойной тап = NFS-полёт. Полёт масштабируется по расстоянию. → V1·10
R7U_0 · V1 / M3
Ворота на выходе, не нытьё
Панель проблем по требованию: измерено vs норма, источник, 3 призрака. Жёсткость — куб закона ×1.42. → V2·04
imos walkthrough · P5/S1
Таблица переменных + Паспорт
Construction / Connection_situation / Back; и взрыв-схема изделия с деталями и фурнитурой. → V2·05, V2·07, V1·11
F1/F2 field · I2/D1-D3
Генерация + decor вне пути
Узкое место — конструктор. Генерируем 4 кухни; техника = ограничения; фасады поздно, через «Лист фасадов». → вся V3
R7U_0 · M5 / F
«Сколько листов» с зубами
Счётчик листов — валюта мастера; формула защищает малые группы декора (min 0.5 листа). → V3·05
DB/19 §1 · кольца
Частота = расстояние
M→Ring 0 жест, H→контекст, P→фаза, W→профиль, A→амбиент. Закон размещения каждого контрола. → V2·01

03 Честная заметка о расхождениях

10_UI_PRINCIPLES v1.0 («пять входов», «нет орбиты») помечен в 19_FUNCTION_MAP как замещённый: примат — за линией/секцией, кольцами и ручной орбитой + NFS-ассистом. V1 держится ваших формулировок там, где они расходятся с локами R7 (например «свободная орбита»), и это помечено прямо в шапке V1. V2 и V3 строго следуют закреплённым решениям R7. Так у вас на руках обе крайности — чистое видение и дисциплина исследований — плюс гибрид-поток между ними.
